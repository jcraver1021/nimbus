# Nimbus

Nimbus is a small, from-scratch cloud for experimenting with distributed systems: real services, a supervisor and a dashboard, plus tools to inject failures and a simulated customer base that reacts to them. It’s also a test bench for system designs: build a solution on top of Nimbus services, then degrade its dependencies and measure how far it can bend before it breaks.

Nimbus is built for learning. Do not use it in any production environment.
